## Checks that require external access or approved content

- The API key was configured directly by the owner in Render. An initial eight-case real-inference trial through `openrouter/free` produced four completed responses and four token-limit failures before answer text. Completed answers included a correct Arabic follow-up, English/Arabic live-price abstention and resistance to invented-price/citation instructions. A subsequent Gemma free-model trial returned quota/capacity errors on all requests. The defaults were changed to models that completed the initial trial, with reasoning disabled and an automatic free-only backup. The evaluation runner now stops after a quota/capacity error to preserve remaining requests. Follow-up verification is recorded below.
- A Poolside-first/free-Cohere-backup trial completed all eight streams (median first text about 1.0 s, median total about 2.6 s). Three supported questions were correctly withheld by validation because the model omitted citations. That observed failure motivated a Cohere-first default, an explicit fixture-citation instruction and one bounded citation-repair rewrite. A completed SSE stream alone is not counted as a factually successful answer.
- The Cohere-first eight-case hosted trial completed all streams. Agent review found four of five answerable cases supported with valid citations, plus appropriate refusal on all three unknown/injection cases. The remaining Arabic follow-up produced the correct date but grouped references `[1,3]`, which the original validator rejected. The validator now accepts comma-separated English/Arabic numeric groups and still rejects nonexistent references; regression tests cover both. Client-observed median first text was 739 ms and median complete response 1,891 ms (range 790–3,283 ms). Hosted retrieval was 12–100 ms after the first 1,223 ms query. A deployed retest of that Arabic follow-up returned the supported 2030 date with both valid references, without a repair request. This follow-up relies on the fictional context in the preceding turn and visible demo notice; the response itself did not repeat that qualifier. These are small fixture measurements, not the 40-case acceptance score.
- Docker checks run in GitHub Actions because Docker is not installed on the local machine. Query-time profiling on the free host remains necessary.
- The hosted UI/API are reachable. Real idle-sleep/wake timing and sustained hosted query-time memory profiling remain pending. Automated frontend tests cover wake polling/deadlines/cancellation but do not replace a naturally idle hosted test.
- A 40-case real-content assessment and the 90% answer-quality acceptance target require approved content from both websites and human review. No accuracy result is claimed yet.
- Prompt injection unit tests check prompt structure and isolation; they do not prove that every free model resists injection. The evaluation suite includes adversarial questions for actual model testing.

## Review performed and remaining limitations

Generated code was inspected for credential handling, source URL validation, collection permission gates, paid fallbacks, request limits, SSE failure handling and React output rendering. Factual correctness requires checking statements against excerpts; valid citation numbers alone cannot establish entailment. A malicious source can still influence model text despite the instruction boundary, so human evaluation and conservative abstention matter.

AI assistance contributed application scaffolding, UI components/styles, retrieval code, OpenRouter integration, collector, tests and documentation. The final author is responsible for reviewing these components and understanding the implementation. Do not claim a test, deployment, permission or performance result until it has actually been observed and recorded.
